## Поведение приложения

Растяжка карточек возникает только от протяжки пользователя. Начальная загрузка, автоматическое обновление и кнопка обновления не сдвигают блоки. Переходы между экранами используют затухание 150 мс. Поиск — общий компактный элемент 40 dp.

История открывает события, задачи доступны отдельной кнопкой. Подробности события показываются в прокручиваемом диалоге. В аудите нет плашки «есть изменения» и автоматически выбранного сервера; явный фильтр остаётся видимым и снимается пользователем.

Копирование IP и адресов сопровождается плашкой. Настройки используют единые карточки с пояснениями. Категории Telegram и телефона раскрываются по нажатию. Уведомления телефона получают новые события независимо от выключателя и интервала Telegram; начальная история не рассылается, повторные ID отсекаются.

В терминале Ctrl изменяет следующую клавишу. Дополнительные клавиши расположены в одной горизонтально прокручиваемой строке над клавиатурой; при выходе клавиатура скрывается.

Резервные копии доступны в «Сервисах» после 3x-ui и в карточке сервера. Цель → архив → проверка состава → серверный план → подтверждение. Защитная копия включена по умолчанию. Применение использует подготовленный план v3; повтор после неопределённого ответа сохраняет request_id. Пароль архива остаётся на панели.

Перезапуск Bot4VPS запускается из мониторинга службы. После подтверждённого восстановления связи окно закрывается через секунду. Ошибки и необходимость входа сохраняют соответствующие действия.

## Защита и подключение

Цифровая панель PIN учитывает системные отступы и высоту экрана. Приложение блокируется при сворачивании. PIN приложения содержит 4 цифры. Вход, создание и смена используют отдельный экран с точками и встроенной цифровой панелью. При повторе нового PIN первый ряд точек остаётся заполненным, второй показывает повторный ввод. После четвёртой цифры выполняется действие; системная клавиатура для PIN не вызывается. Смена сначала проверяет текущий PIN. Биометрия появляется после включения блокировки: текущий PIN → системное подтверждение отпечатка → сохранение биометрии. Криптооперация с данными выполняется после подтверждения, ошибки Android не подменяются неверным PIN. Отмена и устаревшие результаты не меняют новую попытку. Повторные ошибки PIN включают сохраняемую задержку. При обновлении с 1.1 прежний пароль или биометрия подтверждают создание PIN; до завершения содержимое скрыто.

Мастер-ключ открывается последовательно: пароль панели → подтверждение владельца → ключ. Сворачивание очищает окно и блокирует приложение. Защищённое содержимое скрыто на снимках и в последних приложениях.

Привязка создаётся через доверенную Web-панель; [подробная инструкция](connection.md). Отдельный API требует подтверждённый ключ устройства при любом состоянии Web-авторизации. TLS-ключ сервера закрепляется в телефоне; первая передача кода через HTTP требует доверенной сети. Запросы отмечаются как `phone` для аудита. Отзыв телефона и выключение API доступны через Web.

В «Ещё → Настройки → Обновления» размещены два блока: «Панель Bot4VPS» с проверкой/установкой сервиса и «Приложение Bot4VPS Mobile» с проверкой/скачиванием APK. Автоматические проверки включаются отдельно. В «О программе» остаются сведения о проекте и версиях. Приложение проверяет ui/mobile/release.json на GitHub независимо от версии панели. Перед системной установкой проверяются размер, SHA-256, пакет, версия и сертификат APK.

## Проверки

Метаданные опубликованного APK — в [release.json](../../ui/mobile/release.json). Подробные отчёты и карта R8 хранятся локально вне исходников. Unit-тесты, lint и контрактные проверки не подтверждают интерфейс или реальные SSH-операции на телефоне. Проверка Android-устройства и независимый аудит безопасности не проводились.
