# Bot4VPS Mobile

Нативный клиент Bot4VPS для Android 8.0 и новее. Первичная настройка сервиса выполняется через Web-панель; приложение управляет уже настроенной установкой.

## Документация

- [Подключение и безопасность](connection.md): отдельный API, сетевой доступ, привязка и отзыв телефона, устранение ошибок.
- [Сборка и публикация APK](development.md): инструменты, подпись, проверки и обновление приложения независимо от сервиса.
- [Сценарии приложения](workflows.md): разделы, действия и соответствие мобильной Web-панели.

Краткие подсказки доступны в Web-панели: **Настройки → Мобильное приложение**. Пошаговая инструкция также включена в [справочник Web-панели](../../ui/web/faq.html#mobile-app).

## Установка

В Web-панели откройте **Настройки → Мобильное приложение** и нажмите **«Скачать APK»**. Файл можно получить через настроенного Telegram-бота; при выключенном Telegram скачивание из Web остаётся доступным. Установку подтверждает Android.

APK и сведения о текущей версии находятся в [`ui/mobile`](../../ui/mobile), исходники — в [`ui/Bot4VPS-Mobile`](../../ui/Bot4VPS-Mobile). Документация хранится только в корневом `docs/mobile`.

## Возможности

- Обзор с графиками, серверы и группы, мониторинг, события, история задач и аудит.
- Управление Docker, WireGuard и 3x-ui, файлы и запуск скриптов.
- SSH-терминал с Ctrl и дополнительными клавишами.
- Резервные копии и восстановление с просмотром плана перед применением.
- Уведомления телефона независимо от настроек доставки Telegram.

Списки обновляются протяжкой вниз. Очистка событий и истории задач требует подтверждения на текущем экране; активные задачи продолжают работать.

## Блокировка приложения

В настройках безопасности включите отдельный PIN-код из четырёх цифр. Ввод и подтверждение проходят на экране с точками и цифровой панелью. После включения PIN появляется настройка биометрии Android: сначала требуется текущий PIN, затем системное подтверждение биометрии. При сворачивании приложение блокируется.

PIN защищает вход в приложение на телефоне. Просмотр мастер-ключа дополнительно требует пароль панели и подтверждение владельца.

## Обновления

В **Ещё → Настройки → Обновления** доступны два блока: **«Панель Bot4VPS»** для обновления сервиса и **«Приложение Bot4VPS Mobile»** для проверки и скачивания APK. Автоматические проверки включаются отдельно.

Приложение получает метаданные и APK из публичного каталога проекта на GitHub. Новая версия APK не требует обновления сервиса или отдельного GitHub-релиза. Перед установкой проверяются размер, SHA-256, пакет, версия и сертификат подписи; установку подтверждает Android.
