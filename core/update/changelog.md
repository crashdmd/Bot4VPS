# Changelog Bot4VPS

Реестр версий для встроенного updater'а. Заголовки `## X.Y.Z` используются
для определения списка версий (откат доступен только на 3.0.0 и новее).
Ветка main всегда содержит актуальную версию сверху.

## 4.0.0

# 🚀 Bot4VPS v4.0.0

## 🌐 Web UI

- Добавлен новый Dashboard с общей информацией о состоянии Bot4VPS и системы.
- Добавлен мониторинг машины, на которой работает Bot4VPS.
- Добавлен просмотр логов Bot4VPS непосредственно из Web UI.
- Добавлен перезапуск Bot4VPS из Web UI.
- Добавлено управление Telegram-ботом из Web UI:
  - включение и отключение;
  - перезапуск;
  - изменение Telegram Token;
  - изменение пользователя.
- Добавлена возможность отключить автоматическую проверку обновлений.
- Доработана мобильная адаптация Web UI.

## 🔄 Обновление и откат

- Добавлена встроенная система обновления Bot4VPS.
- Добавлена автоматическая и ручная проверка новых версий.
- Перед установкой обновления отображается changelog новой версии.
- Добавлено резервное копирование перед обновлением.
- При неудачном запуске новой версии выполняется автоматический откат.
- Добавлена история обновлений.
- Добавлен ручной откат на доступные версии через GitHub Releases.
- Откат доступен до версии **3.0 включительно** — это минимальная версия, в которой уже присутствуют необходимый Web UI и инфраструктура обновлений.
- Список доступных для отката версий хранится в локальном `core/update/changelog.md`.

## 🐳 Docker

- Локальная библиотека Docker Compose теперь может использоваться как **локальная копия/резерв конфигурации** проекта: compose-файла, `.env` и дополнительных конфигурационных файлов.
- При создании контейнера с несколькими опубликованными портами добавлена возможность выбрать, **какой именно порт открыть** для перехода к сервису.
- Доработано отображение и управление Docker из Web UI.

## 🐛 Исправления

- Исправлена полная проверка Docker и WireGuard при отсутствии серверов.
- Исправлено зависание Telegram-сообщения «Идёт полная проверка сервисов...» при отсутствии серверов.
- Исправлено отображение результата задач в Web UI, когда live output отсутствует.
- Исправлена ошибка Telegram `unsupported start tag` при специальных символах в результатах проверок.
- Заменены оставшиеся нативные `confirm()` в Web UI на общие модальные подтверждения.
- Исправлены проблемы мобильного отображения таблиц, кнопок и панелей действий.
- Исправлены отдельные проблемы отображения WireGuard, Docker, Compose и Скриптов на небольших экранах.
- Исправлено кэширование обновлённых Web-ресурсов.
