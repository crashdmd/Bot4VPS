# Bot4VPS

Управление VPS и домашними серверами по SSH: мониторинг, уведомления, установка сервисов, выполнение скриптов и резервное копирование.

Bot4VPS устанавливается на ваш сервер и предоставляет четыре интерфейса управления: Web-панель, Android-приложение, Telegram и консольное меню. Все интерфейсы работают с общей системой управления, настройками и списком серверов.

## Возможности

- **Мониторинг:** доступность серверов, нагрузка, память, диски и SSL-сертификаты.
- **Уведомления:** сообщения о проблемах и восстановлении доступности.
- **Управление:** SSH-терминал, ключи, firewall и системные пакеты.
- **OpenWrt:** подключение роутеров, мониторинг, настройка сети и управление сервисами.
- **Сервисы:** установка и обслуживание WireGuard, Docker и 3x-ui.
- **Автоматизация:** запуск собственных shell-скриптов с параметрами.
- **Резервное копирование:** создание и восстановление резервных копий серверов и самого Bot4VPS.
- **Контроль:** история операций, аудит действий и графики метрик.

## Установка

Требования: Debian или Ubuntu с systemd, подключение к Интернету и права root.

```bash
curl -fsSL https://github.com/crashdmd/Bot4VPS/releases/latest/download/install.sh | sudo bash -s -- install
```

Установщик предложит выбрать режим работы: только Telegram или Web + Telegram. Он настроит системную службу и подготовит данные для первого входа. Для Web-панели можно сразу настроить HTTPS.

После установки консольное меню доступно командой:

```bash
bot4vps
```

> Установщик выполняется с правами root и вносит изменения в конфигурацию сервера.
