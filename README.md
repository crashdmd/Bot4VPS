# 🚀 Bot4VPS

Telegram-бот для удобного управления VPS и домашними серверами через SSH.

> **Примечание:** Проект создавался как инструмент для личного использования, но может быть полезен и другим пользователям. При разработке активно использовались возможности ИИ.

---

# Возможности

## 🖥 Управление серверами

* Группировка серверов (`home`, `vps` и пользовательские группы)
* Пошаговый мастер добавления серверов
* SSH-аутентификация:

  * по паролю
  * по приватному ключу
* Быстрая смена типа авторизации (пароль ↔ SSH-ключ)
* Поддержка отдельного sudo-пароля при авторизации по SSH-ключу
* Автоматическое сохранение sudo-пароля при смене типа авторизации
* Сохранение SSH-ключа при возврате на авторизацию по паролю
* Автоматическая проверка существования SSH-ключа
* Автоматическая проверка SSH при добавлении и редактировании
* Возможность сохранить изменения даже при ошибке проверки SSH
* Просмотр состояния сервера:

  * Uptime
  * Load Average
  * Использование RAM
  * Использование диска
  * Диагностика ошибок SSH
* Перезагрузка сервера
* Редактирование и удаление серверов

---

## 🔑 Управление SSH-ключами

* Создание нового SSH-ключа
* Вставка существующего приватного ключа
* Просмотр содержимого ключа
* Переименование ключа
* Удаление ключа с подтверждением
* Автоматическая проверка существования SSH-ключей

---

## 🖥 Мониторинг серверов

- Автоматическая ежедневная проверка SSL-сертификатов.
- Уведомления в Telegram:
  - успешное обновление SSL-сертификата;
  - истечение срока действия SSL-сертификата.
- Гибридная проверка доступности (Ping / HTTP, если ICMP отключен).
- Ручная проверка доступности и SSL-сертификатов для выбранной группы серверов через меню администрирования.

---

## 📜 Выполнение скриптов

* Запуск Shell-скриптов через Telegram
* Поддержка пользовательских параметров (`# BOT_PARAM`)
* Поддержка условных параметров (`# BOT_OPTION`)
* Выполнение команд через `sudo`
* Живой вывод процесса выполнения
* Автоматическое обновление информации SSL после выполнения Certbot-скриптов
* Просмотр списка скриптов
* Удаление скриптов через интерфейс бота

# Требования

* Python 3.11+
* Telegram Bot Token

# Установка

Клонирование репозитория:

```bash
git clone https://github.com/crashdmd/Bot4VPS.git
cd Bot4VPS
```

Создание виртуального окружения:

```bash
python3 -m venv venv
source venv/bin/activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

---

# Конфигурация

Создайте файл конфигурации:

```bash
cp config.example.json config.json
```

Отредактируйте `config.json`:

```json
{
    "bot_token": "YOUR_BOT_TOKEN",
    "allowed_users": [
        123456789
    ]
}
```

Создайте необходимые директории:

```bash
mkdir -p scripts keys backup logs
```

---

# Запуск

```bash
python3 bot.py
```

---

# Автозапуск через systemd

Создайте сервис:

`/etc/systemd/system/bot4vps.service`

```ini
[Unit]
Description=Bot4VPS Telegram Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/bot4vps
ExecStart=/opt/bot4vps/venv/bin/python /opt/bot4vps/bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Примените изменения:

```bash
systemctl daemon-reload
systemctl enable --now bot4vps
```

Проверить статус:

```bash
systemctl status bot4vps
```

Просмотреть журнал:

```bash
journalctl -u bot4vps -f
```

# Архитектура

Проект разделён на несколько независимых слоёв:

* **UI (`ui/telegram`)** — взаимодействие с пользователем через Telegram.
* **Core (`core`)** — бизнес-логика проекта.
* **Storage** — работа с конфигурацией и данными.
* **Event Service** — единая система событий и уведомлений.
* **SSH Layer** — выполнение команд на удалённых серверах.

Модули мониторинга не взаимодействуют с Telegram напрямую. Они создают события через `Event Service`, который записывает их в журнал, при необходимости помещает в очередь уведомлений и передаёт пользовательскому интерфейсу.

---

# Особенности

* При авторизации по паролю пароль автоматически используется и для выполнения команд через `sudo`.
* При авторизации по SSH-ключу можно отдельно сохранить, изменить или удалить `sudo`-пароль.
* При смене типа авторизации бот автоматически сохраняет необходимые параметры подключения.
* При отсутствии SSH-ключа бот предложит выбрать существующий или добавить новый.
* Карточка сервера отображает понятные причины ошибок SSH вместо технических сообщений.
* Централизованная система событий позволяет легко добавлять новые виды мониторинга без изменения Telegram-интерфейса.

---

# Безопасность

* Доступ к боту имеют только пользователи из `allowed_users`.
* При каждом изменении серверов автоматически создаётся резервная копия `servers.json` в каталоге `backup/`.
* SSH- и sudo-пароли не отображаются в интерфейсе бота.
* Приватные SSH-ключи доступны для просмотра только через раздел управления ключами.
