# Bot4VPS Mobile

В этом каталоге хранится проверенный release APK приложения для Android и `release.json` с версией, размером и SHA-256. Web-панель предлагает скачать этот APK либо отправить его настроенному получателю Telegram. Выключенный Telegram не мешает скачиванию.

Подключение телефона описано в справочнике Web-панели: **Настройки и безопасность → Мобильное приложение**.

При замене APK обновите метаданные после проверки подписи, версии и контрольной суммы. Сохраняйте прежний ключ подписи для установки обновления поверх приложения.
