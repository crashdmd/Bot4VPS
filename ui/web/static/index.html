Код подтверждения отправляется в Telegram. Введите его и задайте новый пароль.

    
Telegram недоступен или код не приходит? Смените пароль через консоль на сервере: bot4vps → 2. Безопасность → 3. Сменить пароль доступа

Первичная настройка

Вход невозможен

    

      
Администратор не задан, код первичной установки не выдан.

      
Подключитесь к серверу по SSH и выполните:

        bot4vps → Восстановление → Код первичной установки

      
Либо задайте пароль напрямую:

        bot4vps → 2. Безопасность → 3. Сменить пароль доступа

    

  







  

    

    
Код истёк

    

      
Код первичной установки действителен 10 минут и уже истёк.

      
Подключитесь к серверу по SSH и выполните:

        bot4vps → Восстановление → Код первичной установки

      
Новый код также будет действителен 10 минут.

    

  







  

    
🔑 Просмотр мастер-ключа

    

      
Мастер-ключ критически секретен. Для подтверждения владения введите пароль учётной записи.

      
      
    

    

      
Пароль принят. Введите код подтверждения, чтобы получить мастер-ключ.

      
      
      
      

        
        
      

      
Если у вас нет доступа к Telegram или сам сервис в данный момент испытывает трудности, вы можете посмотреть ключ через консоль управления сервисом Bot4VPS (bot4vps → 2. Безопасность → 5. Мастер-ключ).

    

    

      
⚠️ МАСТЕР-КЛЮЧ — КРИТИЧЕСКИ СЕКРЕТНЫЕ ДАННЫЕ
НИКОМУ не сообщайте этот ключ и не передавайте третьим лицам. Храните в безопасном месте. Не сохраняйте в открытого виде в чатах, тикетах, репозиториях. Потеря ключа делает зашифрованные данные невосстановимыми.
